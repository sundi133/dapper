A component is considered **in-scope** if it can be reached, directly or indirectly, by a network request to the deployed application at {{WEB_URL}}. This includes:

**Injection Source Definitions (black-box):**
- **Command Injection Source:** A user-controlled input on a network-reachable endpoint that plausibly flows into a shell/system command (e.g., an export, ping, conversion, or filename feature).
- **SQL Injection Source:** A user-controllable input that plausibly reaches a database query (e.g., search, filter, sort, or id parameters).
- **LFI/RFI/Path Traversal Source:** A user-controllable input that plausibly influences a server-side file path (e.g., `file=`, `path=`, `template=`, `download=`).
- **SSTI Source:** A user-controllable input that is echoed into server-rendered output.
- **Deserialization Source:** An opaque serialized/base64 blob in a cookie or request body.

**Common Vectors:** HTTP params/body/headers/cookies, file uploads/names, URL path segments, stored data reflected later, webhooks, session values, GraphQL arguments.
